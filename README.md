# RoyalFelt Poker

פוקר בין חברים בכסף וירטואלי, בסגנון GGPoker: טקסס הולדם ואומהה 4/5/6 קלפים, שולחנות קאש וטורנירי Sit & Go, ובוטים חזקים שתמיד יושבים בשולחנות.

## הרצה מקומית

```bash
npm install
npm start          # http://localhost:3000
npm test           # סימולציית קאש + טורניר מלא
```

## כניסה של חברים

- כל חבר נרשם עם **כינוי ומספר טלפון**. הבקשה מגיעה למנהל, והוא מאשר או חוסם אותה מכפתור **ניהול** בראש המסך.
- אחרי אישור, המכשיר נשמר ולא צריך להירשם שוב. כניסה ממכשיר חדש דורשת אישור נוסף.
- **מי המנהל:** אם מוגדר `ADMIN_PHONE`, המספר הזה הוא המנהל. אחרת, מי שנרשם ראשון הופך למנהל.
- `ADMIN_PIN` (לא חובה): אם הוגדר, המנהל שנכנס ממכשיר או דפדפן חדש מתבקש להקליד אותו. אם לא הוגדר, מספר המנהל נכנס מכל מכשיר בלי קוד.
- רק המנהל מוסיף צ'יפים: בפאנל יש שדה כמות ליד כל חבר. חבר שנגמרו לו הצ'יפים לוחץ "בקש צ'יפים מהמנהל" והמנהל מקבל התראה.

## מה יש

- **קאש**: 6 שולחנות (הולדם 6 ו־9 שחקנים, PLO4, PLO5, PLO6). הבוטים ממלאים מושבים ומפנים מקום לחברים.
- **טורנירים (Sit & Go)**: 4 טורנירים עם באי־אין, סטאק התחלתי, בליינדים שעולים לפי זמן, הדחות ופרסים (65/35 ב־6 שחקנים, 50/30/20 ב־9). דקה אחרי שחבר ראשון נרשם, הבוטים משלימים את השולחן והטורניר מתחיל, או מיד בלחיצה על "התחל עכשיו". מי שעוזב באמצע ממשיך לשבת על "טייס אוטומטי" (צ'ק/פולד) ויכול לחזור.
- **שולחן פרטי לחברים**: בלובי, "➕ שולחן פרטי לחברים" (רק למנהל) פותח שולחן עם שם, משחק, בליינדים ומספר שחקני AI. "📨 הזמן חברים" שולח קישור (בפלאפון נפתח חלון שיתוף לוואטסאפ). מי שנכנס דרך הקישור מגיע ישר לשולחן אחרי אישור, ורק מוזמנים רואים אותו. שולחן בלי חברים נסגר אחרי שעתיים.
- **בונוס וג'קפוט ידיים**: רק על רביעייה ומעלה, בכל המשחקים, למי שמנצח בשואודאון עם הקלפים שלו. הבונוס מכפיל את מה שזכית (רביעייה x10, סטרייט פלאש x15, רויאל x20, עד 200 ביג בליינד), ובנוסף ג'קפוט קבוע: רביעייה 500 ביג בליינד, סטרייט פלאש 1,000, רויאל 2,500 (בטורניר 5/10/25 באי־אינים לקופה).
- **סטטיסטיקה**: לשונית "מובילים" מראה ניצחונות ואחוזים לכל שחקן, בלי ידיים שנזרקו לפני הפלופ, ואת אחוז הידיים שהוא משחק. לשונית "סטטיסטיקה" מראה אילו קלפים ואילו ידיים יצאו הכי הרבה בשולחן.
- **תמונת פרופיל**: לחיצה על העיגול בסרגל העליון מעלה תמונה שמופיעה ליד השם בשולחן.
- **פלאפון**: האתר מותאם למסכים צרים, ואפשר להתקין אותו במסך הבית (בכרום: תפריט ← הוספה למסך הבית, באייפון: שיתוף ← הוסף למסך הבית).
- **חוויה**: צלילים (עם כפתור השתקה), אנימציות חלוקה וצ'יפים, באנר וקונפטי על סטרייט ומעלה, חגיגה על ניצחון בטורניר, שעון מתקתק ב־5 השניות האחרונות.
- **בוטים**: טווחים לפי פוזיציה, 3-בט/4-בט, push/fold בסטאק קצר, אקוויטי מונטה קרלו מול טווח היריב, c-bet, סמי־בלוף ובלופים, וסגנונות שונים (TAG, LAG, NIT, PRO).

## עלייה לאוויר ב־Render

1. ב־[Render](https://render.com): **New → Blueprint**, ובוחרים את ה־repo הזה. הקובץ `render.yaml` מגדיר הכול.
2. ממלאים את `ADMIN_PHONE` (המספר שלך) ו־`ADMIN_PIN` (קוד סודי לבחירתך).
3. אחרי ה־deploy מקבלים כתובת `https://...onrender.com` ששולחים לחברים.

התוכנית ב־`render.yaml` היא החינמית. השרת נרדם אחרי כרבע שעה בלי פעילות ומתעורר בכניסה הבאה (לוקח כדקה). אין בה דיסק, ולכן בכל הפעלה מחדש החברים, האישורים והיתרות מתאפסים: כל חבר נרשם שוב ומחכה לאישור שלך. המנהל (`ADMIN_PHONE`) נכנס תמיד בלי אישור. כדי לשמור נתונים לאורך זמן אפשר לעבור ל־Starter ולהוסיף דיסק עם `DATA_DIR=/var/data`.

## הגדרות

| משתנה | תפקיד |
|---|---|
| `PORT` | פורט השרת (ברירת מחדל 3000) |
| `DATA_DIR` | תיקיית הנתונים (`users.json`, `bankrolls.json`) |
| `ADMIN_PHONE` | מספר הטלפון של המנהל |
| `ADMIN_PIN` | קוד מנהל לכניסה ממכשיר חדש |

השולחנות והטורנירים מוגדרים ב־`DEFAULT_TABLES` ו־`DEFAULT_TOURNAMENTS` בתוך `shared/lobby.js`.

## מבנה

| קובץ | תפקיד |
|---|---|
| `shared/engine.js` | קלפים, הערכת ידיים, מכונת המצבים של השולחן |
| `shared/bot.js` | הבוטים |
| `shared/lobby.js` | שחקנים, יתרות, שולחנות קאש, טורנירים וניהול בוטים |
| `auth.js` | הרשמה עם טלפון ואישור מנהל |
| `server.js` | Express + Socket.IO |
| `public/` | הממשק בדפדפן (`fx.js` = צלילים ואפקטים) |
| `test/` | בדיקות: הערכת ידיים, סדר פעולות, פוט לימיט, שימור צ'יפים, טורניר מלא |
| `scripts/build-demo.js` | בונה גרסת הדגמה שרצה בדפדפן בלי שרת |
